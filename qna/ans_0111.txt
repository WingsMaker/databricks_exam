Photon is a native vectorized execution engine written in C++ that speeds up SQL and DataFrame operations. It operates seamlessly on standard table formats (like Delta and Parquet) and file formats (like CSV and JSON) while supporting a wide array of Spark SQL commands. Official documentation details Photon's capabilities under What is Photon? on Databricks Docs.
