Auto Loader can use file notification services (cloudFiles.useNotifications = "true") and cloud queues (like AWS SQS or Azure Event Grid) to receive notifications when new files are added. This avoids the need to perform costly directory listings (list calls) on large buckets, which can become slow and expensive at scale. Official documentation outlines this configuration under Configure file notification mode for Auto Loader on Databricks Docs.
